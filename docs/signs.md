# Словарь жестов

Все жесты взяты из русского жестового языка (РЖЯ). Глухие в Казахстане пользуются его местным вариантом, который лингвисты называют казахско-русским жестовым языком (K-RSL). Словарь у них в основном общий, отличаются в основном жесты для национальных реалий.

Источники про язык в Казахстане: [LREC 2022](https://aclanthology.org/2022.lrec-1.271.pdf), [SignLang 2024](https://aclanthology.org/2024.signlang-1.12.pdf), [bes.media](https://bes.media/news/yazikovoy-vopros-kosnulsya-dazhe-gluhih-pochemu-vse-eshe-net-zhestovogo-kazahskogo/), словарь [surdo.kz](http://surdo.kz/rus/about).

## Жесты в приложении

| Жест | Как выполняется | Источник |
|---|---|---|
| ПРИВЕТ | Ладонь раскрыта к собеседнику, пальцы вверх, кисть у плеча, покачивание влево и вправо 2 или 3 раза | [Spreadthesign 1774](https://www.spreadthesign.com/ru.ru/word/1774/privet/0/) |
| ПОКА | Ладонь к собеседнику у плеча, все пальцы вместе сгибаются и разгибаются 2 или 3 раза | [Spreadthesign 10855](https://www.spreadthesign.com/ru.ru/word/10855/poka/0/) |
| СПАСИБО | Кулак касается лба, затем опускается и костяшками касается подбородка | [Spreadthesign 423](https://www.spreadthesign.com/ru.ru/word/423/spasibo/0/), [surdo.kz](http://surdo.kz/rus/dictionary/23/youtube/654) |
| ДА | Перед грудью указательный и средний вытянуты вверх, затем сгибаются в кулак, кисть коротко опускается, как кивок | [Spreadthesign 420](https://www.spreadthesign.com/ru.ru/word/420/da/0/) |
| НЕТ | Раскрытая ладонь одним движением отмахивается от середины груди в сторону | [Сурдосервер](http://www.surdoserver.ru/surdo/word/net) |
| ХОРОШО | Кулак, большой палец вверх, перед грудью | [Spreadthesign 91](https://www.spreadthesign.com/ru.ru/word/91/khorosho/0/), [surdo.kz](http://surdo.kz/rus/dictionary/10/youtube/667) |
| ОТЛИЧНО | Большой и указательный замкнуты в кольцо, остальные пальцы прямые, ладонь вперёд у плеча | [Spreadthesign 1826](https://www.spreadthesign.com/ru.ru/word/1826/otlichnyi/0/) |
| ПЛОХО | Кулак с поднятым мизинцем | [Spreadthesign 1475](https://www.spreadthesign.com/ru.ru/word/1475/plokhoi/0/) |

## Что нужно проверить

У жестов НЕТ, ХОРОШО и ПЛОХО в словарях есть другие варианты. Для НЕТ выбрана отмашка по Сурдосерверу, а не вариант со Spreadthesign. Жест с мизинцем в словаре записан как «плохой».

ДА, НЕТ, ПЛОХО и ОТЛИЧНО не сверены с казахстанскими словарями. Перед показом набор стоит проверить у глухого носителя языка.

## Частые ошибки и подсказки

| Жест | Ошибка | Подсказка |
|---|---|---|
| ПРИВЕТ | Пальцы согнуты | Пальцы прямые, качай ладонью влево и вправо |
| ПРИВЕТ | Ладонь к себе | Разверни ладонь к собеседнику |
| ПРИВЕТ | Рука низко | Подними кисть к плечу |
| ПОКА | Кисть качается в стороны | Кисть на месте, двигаются только пальцы |
| ПОКА | Пальцы сгибаются по одному | Сгибай все пальцы разом, как будто сжимаешь мячик |
| СПАСИБО | Раскрытая ладонь | Сожми кулак |
| СПАСИБО | Касание только в одном месте | Начни у лба, потом опусти кулак к подбородку |
| ДА | Просто кулак без движения | Начни с вытянутых указательного и среднего |
| ДА | Пальцы разгибаются | Согни их в кулак и чуть опусти кисть, как кивок |
| НЕТ | Взмахи туда и обратно | Одно движение от груди в сторону, без возврата |
| НЕТ | Пальцы растопырены | Ладонь открыта, пальцы вместе |
| ХОРОШО | Большой палец вбок | Большой палец вверх |
| ХОРОШО | Пальцы не сжаты | Сожми четыре пальца в кулак |
| ОТЛИЧНО | Кольцо не замкнуто | Соедини кончики большого и указательного |
| ОТЛИЧНО | Остальные пальцы согнуты | Выпрями остальные три пальца |
| ПЛОХО | Поднят не тот палец | Подними только мизинец |
| ПЛОХО | Торчит большой палец | Прижми большой палец к кулаку |
