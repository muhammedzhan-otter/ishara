# Ishara

Ishara переводит жесты рук в текст и речь прямо в браузере. Приложение показывает видеовстречу с собеседником: он говорит, а вы отвечаете ему жестами. Если жест сделан неточно, приложение объясняет, что именно поправить.

Проект сделан на Admit Hackathon 2026, кейс «Motion: камера вместо джойстика», свободное направление.

## Попробовать онлайн

Ссылка появится после первого деплоя.

Нужен компьютер или телефон с камерой и браузер Chrome, Edge или Safari. Когда браузер спросит про камеру, нажмите «Разрешить».

## Запуск на своём компьютере

Нужен Node.js версии 20 или новее.

```bash
git clone https://github.com/OWNER/ishara.git
cd ishara
npm install
npm run dev
```

Откройте в браузере адрес, который напишет команда (обычно http://localhost:5173), и разрешите доступ к камере.

Собрать статическую версию для хостинга:

```bash
npm run build
```

Готовые файлы окажутся в папке `dist`. Для работы камеры сайт должен открываться по https.

## Как это устроено

Руки и положение тела распознаёт MediaPipe (Hand Landmarker и Pose Landmarker) прямо в браузере, видео никуда не отправляется. Файлы моделей лежат в репозитории, поэтому приложение не зависит от внешних серверов.

Логику жестов, подсказки об ошибках и сценарий встречи команда пишет сама поверх точек, которые выдаёт MediaPipe.
